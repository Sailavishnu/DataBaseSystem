# Database Systems Exercises

This workspace contains SQL and database lab materials, plus a few Java/JDBC exercises.

## Contents

- `Hacker Rank/` - SQL practice solutions grouped by exercise.
- `Lab Exercises/` - Core lab notes and scripts.
	- `DDL.txt` - DDL walkthroughs (create tables, constraints, copies, renames).
	- `DML.txt` - DML examples.
	- `NESTED QUERY.txt`, `SETS JOIN.txt` - query patterns and joins.
	- `FUNC_PROC.txt`, `PL SQL.txt`, `TRIGGER.txt` - procedures, PL/SQL, triggers.
	- `VIEWS AND INDEX.txt` - views and indexes.
	- `JDBC/` - Java exercises and sample JDBC apps.
	- `mongo/` - MongoDB sample notes.

## How to use

- Open the relevant `.txt` or `.sql` file and run the statements in your SQL client.
- Files are written in an Oracle-style SQL shell format (e.g., `SQL>` prompts and `DESC`).
- If you want to run these in another RDBMS, you may need to adjust data types and syntax.

## Notes

- Some files include example output (e.g., `DESC` results). These are reference only.
- Keep the prompts and outputs intact if you are using them as lab submission evidence.
